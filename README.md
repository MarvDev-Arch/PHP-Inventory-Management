# Inventory Management System

A web-based inventory management system developed using PHP and MySQL.  
This application is designed to help administrators manage stock data efficiently through a responsive dashboard interface.

---

 Features

- Session-based admin authentication
- Secure login & logout system
- CRUD (Create, Read, Update, Delete) inventory data
- Responsive dashboard using Bootstrap
- Data table management interface

---

 Tech Stack

- PHP (Native)
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

 How to Run This Project

1. Clone this repository
2. Move project folder to `htdocs` (XAMPP)
3. Import database file into phpMyAdmin
4. Run on `http://localhost/project-folder`
5. Login as admin
